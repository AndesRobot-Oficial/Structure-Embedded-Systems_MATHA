# Mecánica y CAD

Base móvil de cuatro ruedas mecanum y estructura de aluminio. Las fotos disponibles están en [evidencias](../../evidencias/README.md).

Geometría del firmware: radio de rueda 0,075 m; suma de semidistancias longitudinal y transversal `lx + ly = 0,385 m`. Este valor no proporciona por sí solo largo y ancho del chasis.

Se incluye la [figura de geometría de la tesis](../../fuentes_tesis/geometria_mecanum.tex) como fuente editable LaTeX, no como plano de fabricación.

No se localizaron CAD nativo, STEP, planos acotados ni despiece mecánico en el material revisado fuera del URDF. Pendientes: recuperar originales, registrar revisión, dimensiones medidas, materiales, perfilería, soportes y tornillería. No se generaron dimensiones ni un CAD sustituto.
