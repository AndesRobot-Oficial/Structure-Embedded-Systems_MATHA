# Procedencia de archivos

| Material | Procedencia |
|---|---|
| Diagramas eléctricos | Siete PNG aportados por el equipo |
| PCB | Proyecto KiCad, librerías y Gerbers aportados en la carpeta del repositorio |
| Firmware y configuración ROS | Código de MARTHA; revisión de origen e7993a90ace9e0272ac43eeeb9a4230fb19da2fe |
| Evidencias | Cuatro fotografías seleccionadas por el equipo y video local |
| Portada | Ilustración conceptual vectorial creada para la documentación |

[Manifiesto de archivos](manifest_archivos.json): huellas SHA-256 de los materiales de diseño, código y medios presentes. Los archivos originales de PCB, firmware, diagramas, fotos y video se conservaron sin modificar su contenido. La carpeta PCB se reubicó conservando sus rutas internas y el video se renombró para su publicación.

La documentación se organiza para el proyecto de MARTHA orientado a RoboCup. No se asignó una nueva licencia ni se modificó la autoría del material aportado.
